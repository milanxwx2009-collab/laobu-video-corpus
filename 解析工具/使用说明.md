# 老布视频批量解析工具 V1.0 · Windows说明

## 只想跑完146部：按这三步操作

1. 用文件资源管理器打开 `D:\My Codex\老布视频研究\解析工具`。
2. 双击 **一键跑完全部视频.bat**，不用输入命令或修改配置。保持窗口打开，并让电脑保持唤醒。
3. 出现「全部146部视频处理完成，结果已保存」后，打开 `D:\My Codex\老布视频研究\全部146部视频结果`。先看「全部视频目录.csv」，再打开「逐部结果」中的对应编号文件夹；汇总和每10部的研究包在「汇总资料」中。

已经完成的10部会跳过，继续处理剩余136部。中途退出或个别视频失败时，再双击同一个文件即可续跑。只有完成情况显示146/146才表示全部成功；未完成的视频目录会明确标注。以下命令行说明供需要调整参数时参考。

原始视频和 `01_转写结果` 为只读输入。工具不会移动、改名或覆盖这些文件；不会上传数据，不会自动安装软件或下载模型。开发验收只运行10部测试素材，其余保持待处理。请先阅读 `测试报告.md` 中的质量限制再决定全库运行。

## 运行环境

已复用项目 `.tools/python`、`.tools/models` 和 `.tools/huggingface`。现有运行时为Python 3.12.14；FFmpeg由imageio-ffmpeg携带；ASR是large-v3-turbo、CPU int8。检测到AMD显卡，没有CTranslate2 CUDA设备，所以使用CPU。

BAT优先使用CODEX_PYTHON，其次读取python_path.txt里的当前Python绝对路径。若路径日后变化，请编辑python_path.txt、设置CODEX_PYTHON，或使用自己已安装的Python调用run.py。依赖清单见requirements.txt；换电脑安装依赖和下载模型需要用户明确许可，本工具不会代为执行安装。显卡驱动或CUDA库不完整时，auto/cuda尝试失败后回退CPU。

## 首次操作

打开本目录的终端，执行：

```bat
启动工具.bat doctor
启动工具.bat scan
启动工具.bat process --limit 1
启动工具.bat export --batch-size 10
```

双击 `小批量启动.bat` 会扫描全部MP4，然后最多处理1部未完成视频；完成视频跳过。双击 `启动工具.bat` 只显示命令说明。

## 输入和输出目录

编辑 `config.json` 的input_dir和output_dir，支持中文、空格、特殊符号和多级文件夹。相对路径按config.json所在目录计算；默认`..`表示项目根目录。不要把输出目录设到旧转写文件目录。model_dir指向本地模型缓存。可以用不同配置隔离试验：

```bat
启动工具.bat --config "D:\研究配置\config.json" scan
启动工具.bat --config "D:\研究配置\config.json" process --limit 1
```

仅扫描另一个视频目录：`启动工具.bat scan --input "D:\素材 有空格"`。扫描只建立索引，不启动识别。视频移动或复制后重新scan，同内容SHA-256对应原ID，旧路径另行保留。

## 测试、恢复和重跑

```bat
启动工具.bat scan --file "D:\素材\测试.mp4"
启动工具.bat process --id LB-0088
启动工具.bat process --title "赌徒之死" --limit 4
启动工具.bat process --resume --limit 5
启动工具.bat process --retry-failed --limit 5
启动工具.bat process --force --id LB-0088
启动工具.bat status
```

默认处理pending/interrupted；--resume同时包含failed；--retry-failed只重试failed。--force只允许指定ID，生成新版本，旧结果和人工核对保留。Ctrl+C中断后用原配置续跑，已完整提交的阶段复用，当前未完成阶段重跑。机器被强制关闭后也可恢复。

未给出--limit或--id时，process拒绝运行。全量开关--all-confirmed只供用户明确批准后使用，本次开发不调用。即使已完成自动运行，仍是未人工听核的工作稿。

所有写入命令互斥：处理期间不要同时扫描、导出或review。实时进度和每段ASR/OCR阶段进度在终端显示，也保存到运行日志。关闭终端不保证已完成当前阶段，恢复以完整阶段检查点为准。

## 手动指定字幕区域

默认auto通过6帧下半部文字投票推定区域。运行后查看 `解析结果/LB-xxxx/current.json` 中artifact_directory下的roi_preview.jpg，红框就是OCR区域。自动区域属于待核候选，如果遗漏上方/多行字幕，请设置roi，再指定ID重跑。

roi为归一化 `[左,上,右,下]`，例如旧《赌徒之死》区域为 `[0,0.60,1,0.72]`，《皇家马戏团》为 `[0,0.70,1,0.80]`。这些只是已有素材参数，不保证新视频相同。sample_interval默认0.4秒，字幕变化后短暂加密到0.2秒；极短闪现仍可能漏识别。

abbreviations用于可解释简写分类，画面WD仍保持WD。不能仅凭简写字典自动编造口播。对未确定词义，字典保留空数组。

## 查看结果与人工核对

每部 `解析结果/LB-xxxx/` 包含要求的metadata、ASR原始JSON、TXT/SRT、OCR JSON/TXT、alignment、structured、review_queue、quality_report和research_packet。音频、ROI预览和截图在runs版本目录；current.json可定位。research_packet.md可直接交给ChatGPT，含全部口播、字幕、差异、原文证据和质量说明。

检索ASR/OCR：

```bat
启动工具.bat search "皇马"
启动工具.bat search "王二"
```

以review_queue.csv中的id附加核对结果：

```bat
启动工具.bat review R-示例ID --author "核对者" --status resolved --apply-transcript --text "听核确认的口播文本" --evidence "已回听该时间段原音频，并查看原画面；具体依据……"
```

status支持pending、resolved、ignored。命令保留原始ASR/OCR，将该条意见加入annotations.json及研究包；只有明确使用--apply-transcript、状态resolved且时间范围与候选字幕完整匹配的核对文本，更新独立候选TXT/SRT和对齐候选，不改原识别。一般意见不要加此开关。若范围仅覆盖一条字幕的一部分，不猜测新的切分时间，只保留独立意见。单条确认不会把整片标成人工完成。不同重跑生成的新疑点仍需要分别核对，不会因时间接近而自动继承人工完成状态。

修正系列归属/集数：

```bat
启动工具.bat metadata LB-0088 --series "赌徒之死" --episode 1 --total 4
启动工具.bat metadata LB-0001 --title "91岁的赌徒"
```

数据库索引保存新信息；历史运行metadata不改写。已完成素材导出时使用当前索引并保留原运行信息。清空系列使用--series ""；集数无法确定时scan保持空，不强行猜测。

旧资料：`启动工具.bat import-legacy`。只读导入原803行核对台账，幂等保存；原视频SHA匹配后，独立保留旧稿815条候选字幕，含修订、补充对白和待核占位，不丢失前次工作。TXT/SRT候选口播可沿用这些旧稿，本次新ASR仍完整保存在raw通道；旧视觉核对不能称为人工听核。测试原资料均保留原目录。

对齐算法/简写字典更新后，可执行 `启动工具.bat realign --id LB-0088`，只用已有ASR/OCR重建对齐并保存新版本，不再跑模型；历史疑点仍保留，不能据此声称人工完成。

## 批量研究导出

```bat
启动工具.bat export --batch-size 10
启动工具.bat export --batch-size 20
```

汇总导出包含全部146部索引、新ASR原文all_segments.jsonl、候选口播all_candidate_segments.jsonl、字幕all_subtitles.jsonl、全库核对台账、旧核对依据legacy_review_records.json、系列关系、研究注释、质量汇总和corpus_manifest。候选口播通过channel区分旧稿与新ASR，不能混同。未处理的ID显式列出，不伪装全库已完成。

每次导出保存独立版本目录。latest.json记录最新目录，batch_001等每批包含10/20部研究包和research_batch.md。已完成素材按稳定ID排序后分批，批次不重复不遗漏。提供给ChatGPT时优先使用research_batch.md，保留每部质量说明。导出不复制原视频、不上传资料；截图与音频用本地source_pointer定位。

## 故障排查

- 找不到Python：检查CODEX_PYTHON；不要使用只有Microsoft Store快捷别名而无运行时的python.exe。
- 本地模型加载失败：doctor检查model_cache_present，确认缓存与model_dir；工具不会联网补下载。
- 找不到原视频：重新scan新目录，以SHA-256找回原ID。原路径内容改变会拒绝用旧ID处理，重新scan会登记新素材。
- FFmpeg错误：检查该素材音轨和日志；单部失败不停止剩余批次。
- 输出视图不完整：`启动工具.bat refresh --id LB-xxxx` 从DB指向的完整版本重建。
- “另一个命令正在写入”：等待正在运行的处理结束；不要删除writer.lock，OS锁会在进程结束释放。
- OCR乱码/大量差异：检查ROI预览，按素材设置区域；OCR/ASR分句不匹配也会产生误报。
