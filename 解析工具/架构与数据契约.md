# 架构与数据契约 V1.0

本工具只在本地读取原始MP4，提取识别资料；不上传资料、不下载视频、不生成文学评价。原视频继续位于原目录，无需移动到“原始视频”。运行入口 `run.py` 优先加载已经验证的 `.tools/python` 依赖，设置离线模型环境变量。

## 模块职责

|模块|文件|职责|
|---|---|---|
|A|laobu/database.py、media.probe|递归扫描，流式SHA-256，稳定素材ID，重复文件路径别名，系列解析|
|B|laobu/media.py Engines.transcribe|FFmpeg全音轨、large-v3-turbo、逐词时间戳、Silero覆盖审计、关闭VAD二次识别|
|C|laobu/media.py Engines.extract_ocr|多帧字幕区域投票，人工ROI，默认0.4秒采样，变化后0.2秒加密，原始置信度与截图|
|D|laobu/quality.py|时间交集对齐、A/B/C/D分类、数字/简写/置信风险、持久核对台账|
|E|laobu/outputs.py|结构化JSON、TXT/SRT、Markdown研究包、全库JSONL和分批研究导出|
|调度|laobu/pipeline.py、cli.py|单模型复用、阶段检查点、独立失败、版本提交、命令行|

## 数据契约

`schema_version=1`、`tool_version=1.0.0`。主研究包为 `transcript_structured.json`：

- `metadata`：video_id、run_id、title、original_filename、source_path/source_paths、sha256、series_id、episode、total_episodes、media、processed_at、parameters、runtime、elapsed_seconds、quality_status、human_review_status、fact_verified。
- `asr`：模型、实际设备、精度、语言、音频时长、原始segments、词级置信度、speech_intervals、gaps、retries。二次识别不自动替换主识别。
- `ocr`：roi、roi_detection及其原文字证据、sampling_interval、decoded_frames、frames原始OCR、segments去重字幕。置信度只是识别器评分。
- `alignments`：id、video_id、start/end、asr_ids、ocr_ids、asr_raw、ocr_raw、candidate_transcript、revision_basis、revision_history、category、difference_types、confidence、human_review_status、speaker_type。
- `reviews`：稳定疑点ID、video_id、时间、类型、原文和证据、pending状态。
- `research`：14个预留字段、literal_candidates与空semantic_analysis。所有候选有素材ID、时间、ASR片段ID和原文；不是事实核验。
- 后续导入旧资料时，可附加 `legacy_review_records` 与 `candidate_segments`，均显式记录旧来源和核验范围；机器主识别始终保留在 `asr`。

时间单位为相对原视频起点的秒，UTF-8编码，CSV加BOM。`transcript_final.txt` 的final只是约定名称，不表示人工定稿。声源标为unknown；不假定全部都是作者旁白。

## SQLite

数据库位于 `数据库/corpus.sqlite`，WAL日志与外键开启。`PRAGMA user_version=1`，新库通过初始迁移创建；高于支持版本的数据库拒绝打开，后续升级必须加入显式迁移，不能自行降级。

数据库包含 videos、source_paths、series、segments、ocr_segments、alignments、review_items、processing_jobs、annotations、legacy_records、corpus_fts。逐段JSON和对应列保存一致原始数据。运行历史以run_id区分；当前完整版本由videos.current_run指向。核对台账去重ID由素材、时间、类型和原始证据生成；不同重跑若发生时间或文字变化，新增记录，历史待核不会删除。

全文检索使用FTS5 trigram；三字符及以上使用安全的字面MATCH；两字姓名使用转义LIKE。只检索当前完整版本的ASR/OCR。故事候选词表可配置，自动补全人物关系不在V1范围内。

## 恢复与提交

每个数据库只有一个写入命令持有OS文件锁；崩溃时锁自动释放，锁文件本身保持存在。扫描、导出、核对修订与处理互斥，避免同时修改。

处理状态：pending → running → completed/failed/interrupted。新命令把遗留running任务标为interrupted。相同参数和依赖版本可复用完整audio、ASR、OCR阶段；正在执行的阶段中断后会重跑该阶段，不能保证从任意音节续接。配置变化或强制重跑建立新阶段目录。

所有JSON/TXT/CSV先写同目录临时文件、flush/fsync，然后os.replace。阶段文件完整写完后才存在完成标志；在 `.work` 生成完整资料后，重命名提交到 `runs/RUN-*`，再SQLite事务写入当前版本。若重命名已成功但DB失败，保留孤立版本，下一次恢复复制其完整检查点再提交，原版本不删除。导出采用类似的临时批次目录提交。

每部素材根目录是可重建展示视图，多文件展示视图不是一次全目录事务；数据库指向的不可变runs目录才是完整版本来源。`refresh`可修复发布中断。音频、截图位于版本目录，根目录 `current.json` 提供绝对路径。

## 自动核对边界

A=规范化文字相同；B=明确简写/数值书写等价候选；C=实质文字冲突；D=缺少通道、低置信或不能可靠对齐。B不能自动视为严重错误，其他文字仍冲突时保持C/D。JC等默认映射只是候选字典，GL/ZW/YS/Z地/走D的未知读法保持空，不能自行扩写。

OCR字幕跨样本相同才去重，不模糊合并不同字。显示边界为相邻取样中点，存在取样误差。OCR内所有文字保留候选类型；自动ROI可能混入标题水印，未确认ROI生成待核记录。未识别取样和低置信帧保存截图；无法确定该帧是否实际有字幕，因此不声称所有未识别截图都代表漏字幕。

VAD、低置信、compression_ratio和片段语言检测只提示风险，无法可靠自动区分作者、影视对白、不同说话人、音乐和音效。主识别固定中文会错识外语，二次检测可能提示外语，也可能漏检。ASR与字幕时间段长度不一致会产生误报。数字等价使用保守整数字写法规则，不用于核实比赛或历史事件。

人工review命令只改变指定核对项状态，修订意见、依据与原状态追加到annotations；不覆盖原文、不删除历史，也不把整片变成人工完成。ignored是暂忽略，resolved是用户声明该项已解决，二者均不证明整片已经逐句听核。
