# 老布视频批量解析与结构化语料库工具

用于在 Windows 上处理本地视频，提取口播与画面字幕，保存逐部研究资料和汇总数据。支持断点续跑、已完成视频跳过、历史版本保留及独立人工核对记录。

## 运行已有项目

打开 `解析工具` 文件夹，双击 `一键跑完全部视频.bat`。工具会扫描素材，跳过已完成的视频，继续处理未完成、中断和失败的视频，最后将结果集中到项目根目录的 `全部146部视频结果` 文件夹。

保持窗口打开，电脑保持唤醒。看到“全部146部视频处理完成，结果已保存”才表示全量成功；中断后再次双击同一文件即可续跑。

## 从代码备份恢复

这个仓库保存源代码、配置、启动文件、测试代码和说明文档。原视频、模型、依赖缓存、数据库、运行日志与解析结果需要从本地项目单独恢复。

1. 将代码恢复到项目根目录，保留 `解析工具` 的目录结构。
2. 将原 MP4 素材放回项目目录。恢复 `.tools` 中的依赖和离线模型；如果使用独立 Python 环境，依赖版本见 `解析工具/requirements.txt`。
3. 按实际情况调整 `解析工具/config.json` 中的输入目录、输出目录和模型目录。默认 `..` 表示项目根目录。
4. 如需指定 Python，可在本机创建 `解析工具/python_path.txt`，写入 Python 可执行文件的完整路径，或设置 `CODEX_PYTHON`。机器专用路径文件不纳入备份。
5. 恢复现有 `数据库` 和 `解析结果` 后可续跑；只有代码和原视频时，将重新建立索引并处理。

工具使用本地模型，不会自动下载模型或上传视频。自动生成的文字是机器处理稿，待核问题保存在核对台账中。

## 代码与文档

- `解析工具/run.py`：命令行入口。
- `解析工具/run_all.py`：一键全量流程及结果集中整理。
- `解析工具/laobu/`：索引、识别、对齐、质量标记、导出与核对逻辑。
- `解析工具/tests/test_core.py`：核心测试。
- [使用说明](解析工具/使用说明.md)、[架构与数据契约](解析工具/架构与数据契约.md)、[测试报告](解析工具/测试报告.md)。

测试报告记录开发时的小批量验证，不代表之后全量运行的实时状态。实时完成情况见本机结果文件夹中的 `完成情况.json`。
